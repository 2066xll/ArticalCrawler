## 开启文章爬取服务器

我将运行以下命令来启动Flask服务器：

```bash
python3 app.py
```

服务器将在端口5001上运行，可通过浏览器访问 http://localhost:5001 来使用文章爬取功能。

### 服务器功能
- 提供文章爬取的Web界面
- 支持异步爬取任务
- 提供任务状态查询
- 支持历史记录查看
- 支持文件下载和在线查看

### 预期结果
- 服务器成功启动，显示"Running on http://0.0.0.0:5001/"
- 可以通过浏览器访问服务器
- 可以正常提交爬取任务

### 注意事项
- 确保已经安装了所有依赖（可以通过`pip install -r requirements.txt`安装）
- 服务器将在前台运行，按Ctrl+C可以停止服务器
