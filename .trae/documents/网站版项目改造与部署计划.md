# 网站版项目改造与部署计划

## 当前状态分析

1. **项目类型**：基于Python Flask的后端应用
2. **主要功能**：文章爬取、多章节导航、文章预览
3. **技术栈**：Python Flask、BeautifulSoup4、Bootstrap 5
4. **部署限制**：Cloudflare Pages不支持Python后端，不适合直接部署

## 改造方案

### 方案：前后端分离

- **前端**：静态网站，部署到Cloudflare Pages
- **后端**：RESTful API，部署到支持Python的平台（如Vercel、Heroku）或使用Cloudflare Workers

### 优势

- 充分利用Cloudflare的CDN和边缘计算能力
- 前端加载速度快
- 后端可以独立扩展
- 支持多种部署选项

## 改造步骤

### 1. 分析当前项目结构

- 前端代码：`templates/` 目录下的HTML文件
- 后端代码：`app.py` 和 `article_crawler.py`
- 静态资源：`static/` 目录下的文件

### 2. 重构后端API

- 将现有的Flask路由改造为RESTful API
- 分离爬取逻辑和渲染逻辑
- 确保API返回JSON格式数据
- 优化API性能

### 3. 重写前端代码

- 使用现代化的前端框架（如Vue.js或React）
- 或者使用静态HTML/CSS/JavaScript
- 实现与后端API的交互
- 保持现有功能不变

### 4. 准备Cloudflare Pages部署

- 创建适合Cloudflare Pages的前端项目结构
- 添加必要的配置文件
- 优化前端代码，确保可以静态部署

### 5. 部署后端API

- 选择适合的后端部署平台
- 配置API端点
- 测试API功能

### 6. 连接前后端

- 修改前端代码，指向后端API端点
- 测试前后端交互
- 优化用户体验

## 实现细节

### 1. 重构后端API

#### API端点设计

| 端点 | 方法 | 功能 |
|------|------|------|
| `/api/crawl` | POST | 提交爬取任务 |
| `/api/task/<task_id>` | GET | 获取任务状态 |
| `/api/history` | GET | 获取历史记录 |
| `/api/view/<filename>` | GET | 查看文章内容 |
| `/api/article/<filename>` | GET | 获取文章详情 |

#### 数据格式设计

```json
// 爬取任务请求
{
  "url": "<url>",
  "format": "txt",
  "output_dir": "./output",
  "next_chapters": 5,
  "prev_chapters": 0
}

// 爬取任务响应
{
  "task_id": "<task_id>",
  "status": "pending"
}

// 任务状态响应
{
  "id": "<task_id>",
  "status": "completed",
  "output_files": ["<file1>", "<file2>", ...]
}

// 文章内容响应
{
  "success": true,
  "filename": "<filename>",
  "content": "<content>",
  "file_type": "txt",
  "prev_article": "<prev_article>",
  "next_article": "<next_article>"
}
```

### 2. 重写前端代码

#### 页面设计

- **首页**：输入URL、选择格式和章节数量、提交爬取任务
- **任务状态页**：显示任务进度和结果
- **文章展示页**：显示文章内容、上一章和下一章导航
- **历史记录页**：显示历史爬取任务

#### 交互设计

- 使用Fetch API或Axios与后端API交互
- 使用Bootstrap 5实现响应式设计
- 添加加载动画和状态指示器
- 优化用户体验

### 4. 部署后端API

#### 部署选项

1. **Vercel**：支持Python后端，部署流程简单
2. **Heroku**：成熟的PaaS平台，支持Python
3. **PythonAnywhere**：简单易用的Python云平台
4. **Cloudflare Workers**：边缘计算平台，适合轻量级API

#### 部署步骤

1. 将后端代码推送到GitHub
2. 连接到部署平台
3. 配置环境变量
4. 部署API
5. 测试API功能

## 部署流程

### 1. 前端部署（Cloudflare Pages）

1. 将前端代码推送到GitHub
2. 登录Cloudflare控制台
3. 选择Pages > Create a project
4. 连接GitHub仓库
5. 配置构建命令和输出目录
6. 点击Deploy site

### 2. 后端部署

1. 将后端代码推送到GitHub
2. 连接到部署平台（如Vercel或Heroku）
3. 配置环境变量
4. 部署API
5. 测试API功能

### 3. 连接前后端

1. 在前端代码中配置后端API端点
2. 测试前后端交互
3. 优化用户体验
