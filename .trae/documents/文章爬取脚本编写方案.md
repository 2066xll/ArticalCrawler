# 文章爬取脚本编写方案

## 1. 技术选型
- **开发语言**：Python 3.8+
- **核心库**：
  - `requests`：发送HTTP请求获取网页内容
  - `BeautifulSoup4`：解析HTML，提取文章内容
  - `lxml`：作为BeautifulSoup的解析器，提供更快的解析速度
  - `python-dotenv`：管理环境变量（可选，用于配置代理等）

## 2. 脚本结构设计
```
article-crawler/
├── article_crawler.py      # 主脚本文件
├── requirements.txt        # 依赖库列表
└── .env                    # 环境变量配置（可选）
```

## 3. 核心功能实现

### 3.1 命令行参数处理
- 支持通过命令行指定文章链接
- 支持指定输出格式（如txt、md）
- 支持指定输出目录

### 3.2 网页获取
- 发送GET请求获取网页内容
- 支持设置User-Agent模拟浏览器
- 支持代理配置（可选）
- 超时处理

### 3.3 内容解析
- 使用BeautifulSoup解析HTML
- 智能识别文章标题、正文、发布时间、作者等元信息
- 处理不同网站的HTML结构差异
- 清理HTML标签，保留纯文本内容

### 3.4 内容输出
- 将爬取的文章内容保存到本地文件
- 支持多种输出格式
- 自动生成文件名（基于文章标题）

## 4. 错误处理
- 网络请求错误处理
- HTML解析错误处理
- 文件写入错误处理
- 日志记录

## 5. 代码实现步骤
1. 创建`requirements.txt`，列出依赖库
2. 编写主脚本`article_crawler.py`
   - 实现命令行参数解析
   - 实现网页获取功能
   - 实现内容解析功能
   - 实现内容输出功能
   - 添加错误处理和日志记录
3. 测试脚本功能

## 6. 使用示例
```bash
# 基本使用
python article_crawler.py https://example.com/article

# 指定输出格式为markdown
python article_crawler.py https://example.com/article -f md

# 指定输出目录
python article_crawler.py https://example.com/article -o ./output
```

## 7. 扩展功能（可选）
- 支持批量爬取多个链接
- 支持爬取整站文章
- 支持图片下载
- 支持内容去重
- 支持定时爬取
