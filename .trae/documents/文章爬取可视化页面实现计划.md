# 文章爬取可视化页面设计

## 功能需求

1. 提供Web界面让用户输入文章URL
2. 支持选择输出格式（txt/md）
3. 支持设置要爬取的章节数量
4. 支持设置输出目录
5. 显示爬取进度和状态
6. 显示历史爬取记录
7. 提供爬取结果下载功能

## 技术栈

* **后端**: Python Flask

* **前端**: HTML/CSS/JavaScript (使用Bootstrap框架)

* **文件处理**: 利用现有爬虫脚本的功能

## 实现步骤

1. **创建Flask应用**: 初始化Flask项目结构
2. **设计HTML模板**: 创建主页面、结果页面和历史记录页面
3. **实现API接口**:

   * 爬取任务提交接口

   * 爬取状态查询接口

   * 爬取结果获取接口

   * 历史记录查询接口
4. **集成现有爬虫功能**: 调用现有的`article_crawler.py`脚本执行爬取任务
5. **实现异步爬取**: 使用线程或Celery实现异步爬取，避免长时间阻塞
6. **添加日志功能**: 记录爬取过程和结果
7. **测试和优化**: 测试各功能模块，优化用户体验

## 文件结构

```
/article_crawler
├── article_crawler.py    # 现有爬虫脚本
├── test_crawler.py       # 现有测试脚本
├── app.py               # Flask应用主文件
├── templates/
│   ├── index.html       # 主页面
│   ├── result.html      # 结果页面
│   └── history.html     # 历史记录页面
├── static/
│   ├── css/            # 样式文件
│   └── js/             # JavaScript文件
└── data/
    └── history.json     # 历史记录存储
```
